### 👨‍💻 Perfil Profesional

Profesional con más de 20 años de experiencia combinando **electrónica y aviónica militar**, **mantenimiento de sistemas críticos** y **desarrollo de software moderno**. Mi trayectoria en las Fuerzas Armadas (Ejército del Aire) forjó una disciplina de trabajo orientada a la tolerancia cero a fallos, diagnóstico metódico y gestión de infraestructuras de alta exigencia.

Actualmente traslado esa mentalidad al desarrollo de software y arquitecturas **AI-First**: construyo aplicaciones escalables, sistemas cliente-servidor, flujos de desarrollo guiados por especificaciones (**Spec-Driven Development**) y pipelines de automatización con agentes de Inteligencia Artificial.

- ✈️ **Aviónica & Sistemas Críticos**: Mantenimiento preventivo/correctivo de aviónica, simuladores de vuelo, instrumentación y redes locales de alta disponibilidad.
- 💻 **Desarrollo Full-Stack Moderno**: Especializado en ecosistemas TypeScript/JavaScript, React 19, Next.js (App Router), PostgreSQL, Prisma ORM y Tailwind CSS v4.
- 🤖 **IA, Multiagentes & Automatización**: Diseño de agentes especializados, gobernanza SDD (GitHub Spec-Kit), RAG y automatización de pipelines de datos.
- 📐 **Arquitectura & Calidad**: Desarrollo guiado por especificaciones, TDD, testing automatizado (Vitest) y despliegues continuos (CI/CD con GitHub Actions y Docker).

### 🔭 Actualmente Construyendo

- ⚙️ **[Elite Agent Bootstrap](https://github.com/BeLc3bU/elite-agent-bootstrap)**: Toolkit integral para desarrollo guiado por especificaciones (*Spec-Driven Development* / SDD) con GitHub Spec-Kit, orquestación de subagentes especializados y quality gates automatizados.
- 🏋️ **OPFORGE**: Plataforma web progresiva (PWA) de periodización física y simulación de exámenes oficiales para Suboficiales EA (Next.js 15.5 + PostgreSQL + Prisma + Docker).
- 🧠 **Pipelines Multiagente**: Sistemas autónomos para extracción, calibración de dificultad y deduplicación semántica de datos formativos y técnicos.
